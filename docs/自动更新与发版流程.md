# 掌门cut 自动更新与发版流程

## 机制概览

- **更新源**：AI 超市托管站点上的 `https://zhangmencut.app.aigzm.com/downloads.json`。官网下载按钮用的也是这份清单，只需维护这一处。
- **检查时机**：软件启动时检查一次，之后每 6 小时检查一次。检查失败（离线、平台实例唤醒中）按“暂无更新”处理，不影响使用。
- **提示界面**：使用原版前端的“发现新版本 vX / 当前版本 vY / 立即更新”弹窗。`mandatory=true` 时不显示“稍后提醒”。
- **安全校验**（主进程 `desktop/updater.cjs`）：
  - 只接受 HTTPS，下载地址必须在白名单内：`github.com`、GitHub 的 Release 资源域名，以及清单所在的主机。
  - 必须带 `bytes` 和 `sha256`。采用流式下载，超出声明大小立即中止，下载完逐字节核对 SHA-256，不一致就删除。
  - 下载地址只取主进程自己读到的清单；网页传来的地址一律不采用。
- **安装方式**：
  - **Windows**：校验通过后打开 NSIS 安装向导，软件随即退出。安装向导沿用注册表里记录的原安装目录，不会动用户数据。
  - **macOS**：解压后再做三项校验——代码签名完整、Bundle ID 与当前应用一致、包内 `package.json` 版本与清单一致。全部通过后，软件退出，由后台脚本替换应用：
    - 旧版移到 `<数据目录>/cache/updates/previous.app`，复制新版并重新验签；
    - 失败会自动还原旧版，最后重新打开应用；
    - 日志写在 `cache/updates/install.log`。
  - **macOS 无法自动替换时**（应用所在目录没有写入权限，或应用是从“下载”目录直接打开、被系统随机化路径），改为在访达中选中新版，提示用户手动拖进“应用程序”。

## 版本号

唯一来源是 `package.json` 的 `version`，以下内容都由它决定：

- 主进程 `app.getVersion()`，自动更新就按它比较版本；
- 打包时 `scripts/patch-app-version.cjs` 写入前端显示的版本和更新比较常量；
- Mac `Info.plist` 中的 `CFBundleShortVersionString` 和 `CFBundleVersion`；
- Windows 安装程序和 exe 的文件版本、卸载项里的版本；
- 安装包文件名。

**每次发版必须提高版本号。** 版本号不变，已安装的用户不会收到更新。

## 发版步骤

1. 修改 `package.json` 的 `version`（例如 `0.2.10` → `0.2.11`）。
2. Mac：用 `scripts/build-companion-mac.cjs` 构建本机助手，再用 `scripts/package-desktop-release-mac.cjs` 打包。脚本会核对应用内版本与发布版本是否一致。
3. Windows：`LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 NSISDIR=$HOME/homebrew/share/nsis node scripts/package-desktop-release-win.cjs .test-data/windows-release-20261016/upstream-app <本机助手.app>/Contents/Resources/xycut <输出目录>`。本机 makensis 装在 `~/homebrew` 下，不设 `NSISDIR` 会找不到 Stubs；不设 UTF-8 语言环境会报 `Bad text encoding`。
4. 将两个安装包上传到 GitHub Releases，核对远端大小和 SHA-256。
5. 更新 `web/downloads.json`：
   ```json
   {
     "version": "0.2.11",
     "published_at": "2026-11-xx",
     "mandatory": false,
     "min_supported_version": "",
     "notes": ["本次更新内容，每条一句"],
     "releases": [{"platform": "darwin", "arch": "arm64", "status": "ready", "url": "https://github.com/…/ZhangmenCut-0.2.11-macOS-arm64-AIGZM.zip", "bytes": 0, "sha256": "…"}]
   }
   ```
   - `mandatory: true`：强制所有人更新。
   - `min_supported_version`：低于该版本的用户强制更新，其余用户可以稍后。
   - 某个平台还没准备好时，把对应条目的 `status` 设为 `uploading` 或直接删掉，该平台的用户就不会收到提示。
6. 打云端包：`node scripts/package-aigzm-cloud.cjs <输出目录> <本机助手.app>/Contents/Resources/xycut`，然后在 AI 超市开发者中心 → 掌门cut → 部署与托管 → 重新部署，上传 ZIP（不超过 20 MB）。**必须先公开 GitHub Release 再部署平台**，否则用户会先看到更新提示，下载时却拿到 404。部署完成后，所有已安装用户会在下次启动或 6 小时内收到提示。

## 注意

- **0.2.10 及更早的版本没有更新检查**，这些用户需要手动下载一次带自动更新的版本，之后才能自动更新。
- Mac 版尚未做 Apple 公证，Windows 版尚未签名。自动更新会校验 SHA-256 和签名完整性，但不会绕过系统安全提示。
- 开发联调（仅限未打包运行）：`ZHANGMEN_UPDATE_ALLOW_LOCAL_HTTP=1 ZHANGMEN_UPDATE_MANIFEST_URL=http://127.0.0.1:端口/downloads.json`。打包后的正式版会忽略这两个变量。
